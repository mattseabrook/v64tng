The Seventh Guest
V.EXE version 1.30
and support files.
08-11-93

This self-extracting archive files contains many new support files for
The 7th Guest. These include updated sound drivers for the PAS 16, the 
Gravis Ultrasound, and many more. A new installation program is provided.

There is also a new player program (v.exe) which requires only 450k
memory.

CAUTION: Because this version of the product uses XMS to a larger degree,
performance may be slightly hampered. You should only use this update if
you have tried V.EXE version 1.22 and 1.24 without success.

Directions:
Copy all these files into your T7G directory. From the T7G directory type:
  
  INSTALL

Choose the appropriate settings for your system.
